# Contour Brand — Landing Page

All project context — brand spec, product system, page structure, tech stack, implementation roadmap — lives in [`AGENTS.md`](./AGENTS.md). Read it before making any decisions.

## Quick reference

- **What:** D2C fashion landing page for women XL–6XL, built around silhouette engineering + accessible pricing
- **Stack:** Next.js + TypeScript + Tailwind CSS (Supabase for backend, Shopify for commerce)
- **Start with:** Sprint 1 (design system) → Sprint 2 (homepage)
- **Brand voice:** Confident, direct, fashionable — never apologetic or patronizing
- **Key differentiator on site:** Fit filters + Fit Finder + silhouette tags on every product

## Rules

- Follow the homepage section order, product page structure, and product data model exactly as specified in AGENTS.md.
- Use the Silhouette Engineering™ tag vocabulary (SMOOTH, DEFINE, BALANCE, LENGTHEN, ENHANCE, SKIM, STRUCTURE) consistently — no synonyms.
- Body-shape system is a styling recommendation, never a restriction. Never tell the customer "you can't wear this."
- Visual direction is minimal fashion editorial. No pink-heavy aesthetics, no body-positive slogans, no cartoon bodies.
- Price display is always in ₹ (INR).
- Fit Finder is rule-based scoring, not AI. Don't claim "AI-powered" anywhere.
